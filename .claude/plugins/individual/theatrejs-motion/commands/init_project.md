# /theatrejs-motion-init_project

Theatre.js - Init Project

## Description

Executes the init_project script for Theatre.js.

## Usage

```bash
/theatrejs-motion-init_project
```

## Implementation

This command runs the `init_project.py` script from the Theatre.js skill, which provides automated assistance for init project.

## Notes

- This command leverages the skill's built-in automation scripts
- For interactive mode, the script will prompt for required information
- Check the skill documentation for detailed script usage
